# Bloomie Days 🌷

เว็บเกมร้านดอกไม้สามมิติเล็ก ๆ สำหรับพักใจ สไตล์ **miniature clay toy** โทนชมพู ครีม และเขียวพาสเทล เขียนด้วย Three.js และ Vite ใช้เครื่องมือฟรีทั้งหมด **ไม่มี API บริการเสียเงิน หรือระบบบัญชีผู้ใช้**

## เล่นอะไรได้ใน V1

- สำรวจหน้าร้านสามมิติพร้อมสวน กระถางดอกไม้ ม้านั่ง และป้ายร้าน
- หน้าร้านเรียบง่าย มีปุ่ม **ยินดีต้อนรับ ร้านเปิดแล้วค่าา** ตรงกลาง ไม่มีคลังดอกไม้หรือข้อความลอยด้านล่าง
- ประตูเปิดก่อนกล้องพาเข้าร้านอย่างนุ่มนวล เพื่อพบ **ฟลอร่า** แมวเปอร์เซียเพศเมียสีขาว ขนฟู ตากลม ใส่กระโปรงชมพู ที่กระพริบตา ขยับหาง โบกมือ และแนะนำตัวเป็นภาษาไทย
- อ่านคำทักทายตามจังหวะของตัวเอง แล้วกด **ไปชมดอกไม้กันค่ะ** กล้องจะเคลื่อนไปด้านข้างสู่ชั้นดอกไม้ เมื่อกล้องถึงแล้วจึงเปิดหน้ารายการดอกไม้
- เลือกชม **50 ชนิด** แบบแบ่งหน้า ครั้งละ 10 ชนิด ค้นหาชื่อไทย/อังกฤษได้ ภาพย่อสร้างจากโมเดล 3D และโหลดเฉพาะหน้าที่กำลังชม
- แตะดอกไม้ในรายการหรือโมเดลที่มองเห็นในมุมดอกไม้ เพื่อเปิดหน้าต่างรายละเอียดแยก มีชื่อ ภาพ ความหมาย และคำบรรยาย ปิดแล้วกลับมารายการ/คำค้นเดิมได้
- ใช้ได้ทั้งเมาส์ จอสัมผัส และคีย์บอร์ดสำหรับปุ่ม/หน้าต่างข้อมูล มีปุ่มลดการเคลื่อนไหว และรองรับ `prefers-reduced-motion`
- ไม่มีระบบขายของ ลูกค้า เงิน เหรียญ หรือเลเวล

โมเดลร้าน แมว ดอกไม้ และภาพในแผงสร้างขึ้นด้วยโค้ดรูปทรงเรขาคณิตของโปรเจกต์นี้ ไม่ใช้ตัวละครอ้างอิงหรือโมเดลที่ดาวน์โหลดมา แบบอักษรแจกฟรีและบันเดิลไว้ในเว็บ จึงไม่ต้องเรียก CDN ขณะเล่น

## เปิดพัฒนา

ต้องมี **Node.js 22.12 ขึ้นไป** (ตรวจด้วย Node.js 24) และ npm:

```bash
npm ci
npm run dev
```

เปิด URL ที่ Vite แสดงใน terminal จากเครื่องของคุณ ภายใต้ `/Bloomie-Days-/` เพื่อให้ตรงกับ GitHub Pages เบราว์เซอร์ต้องรองรับ WebGL 2 และเปิดการเร่งความเร็วกราฟิก แนะนำ Chrome, Edge, Firefox หรือ Safari รุ่นใหม่ เว็บไม่ต้องใช้ `.env`, secret, database หรือ backend

## Build และตรวจสอบ

```bash
npm test
npm run build
npm run preview
```

ผลลัพธ์ใน `dist/` เป็นเว็บ static ใช้กับ static hosting ฟรี หรือรันเซิร์ฟเวอร์ไฟล์ในเครื่องได้ โดยไม่มีค่า API การ build ครั้งแรกต้องดาวน์โหลด dependencies จาก npm; หลังติดตั้งแล้ว ตัวเกมและฟอนต์โหลดจากเว็บเดียวกัน ไม่มีคำขอไปบริการภายนอก

ทดสอบเบราว์เซอร์จริงด้วย Playwright (ฟรี):

```bash
npx playwright install chromium
npm run test:e2e
```

หากมี Chromium ในเครื่องอยู่แล้ว ใช้ `CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e` ได้ ชุดทดสอบรันกับ production build ที่พอร์ต 4173 ภายใต้ `/Bloomie-Days-/` ดังนั้นให้ build ก่อน E2E ทุกครั้ง

Unit tests ตรวจข้อมูล 50 ชนิด/การขยายเป็น 100 ชนิด การแบ่งหน้าและค้นหา สถานะการเดินกล้อง แอนิเมชันฟลอร่า และสร้าง geometry ของดอกไม้ครบทั้งคลัง Browser tests ตรวจลำดับการเล่น การซ่อนคลังก่อนเวลา รายการครบ 50 ชนิด รายละเอียด คำค้น คีย์บอร์ด การกลับหน้าร้าน/replay การลดแอนิเมชัน และกรณีไม่มี WebGL บน desktop/mobile emulation พร้อมจับภาพใน `test-results/`

### วิธีตรวจ flow ใหม่ด้วยตัวเอง

1. หน้าร้านมีปุ่ม **ยินดีต้อนรับ ร้านเปิดแล้วค่าา** ตรงกลาง ไม่มีลูกศร คลังดอกไม้ หรือ caption ลอยใกล้หน้าร้าน
2. กดปุ่มแล้วดูประตูเปิด/กล้องเคลื่อนเข้าร้าน ต้องเห็นเฉพาะคำแนะนำตัวของ **ฟลอร่า** และยังเลือกดอกไม้ไม่ได้
3. อ่านได้ตามสบาย แล้วกด **ไปชมดอกไม้กันค่ะ** ระหว่างกล้องเลื่อนไปด้านข้าง คลังดอกไม้ยังซ่อนอยู่
4. เมื่อถึงชั้นดอกไม้ ให้ลองเปลี่ยนหน้ารายการทั้งห้าหน้า ค้นหา `กล้วยไม้` หรือ `ORCHID` และลองคำค้นที่ไม่มีผลลัพธ์
5. แตะดอกไม้เพื่ออ่านรายละเอียด ปิดด้วยปุ่มหรือ Escape แล้วต้องกลับมายังหน้า/คำค้นเดิม
6. กลับหน้าร้านแล้วเข้าใหม่ ต้องเริ่มที่คำทักทายอีกครั้ง ลองทำซ้ำบนมือถือและเปิดการลดการเคลื่อนไหว: จะข้ามการเคลื่อนกล้อง แต่ยังรอให้กดผ่านคำทักทายด้วยตัวเอง

## โครงสร้าง

```text

  main.js                    เชื่อม UI กับเกม
  style.css                  UI และ responsive layout
  core/visit.js              สถานะ หน้าร้าน → แนะนำตัว → เดินชม → เลือกดอกไม้
  core/catalog.js            การค้นหาและแบ่งหน้า โดยแยกจากการเรนเดอร์
  data/flowers.js            คลังข้อมูลดอกไม้พร้อม ID ถาวรและตัวตรวจสอบข้อมูล
  scene/
    world.js                 renderer, แสง, กล้อง, raycasting, lifecycle
    shop.js                  ร้าน สวน และชั้นวางดอกไม้
    cat.js                   โมเดลและแอนิเมชันฟลอร่า
    flowers.js               factory รูปทรงดอกไม้และกระถาง
    clay.js                  รูปทรงพื้นฐาน วัสดุ และคืนทรัพยากร GPU
  ui/portraits.js            เรนเดอร์ภาพโมเดลตามต้องใช้ พร้อม cache และ SVG fallback
  features/keepsakes/model.js สัญญาข้อมูลสำหรับ V2 (ยังไม่มีหน้าจอใช้งาน)
tests/
  catalog.test.js            คลังข้อมูล กล้อง แอนิเมชันแมว และข้อมูล V2
  e2e/game.spec.js            ตรวจการเล่นในเบราว์เซอร์
```

## เพิ่มดอกไม้ใหม่

คลังปัจจุบันมี 50 ชนิด เพิ่ม object หรือแถวข้อมูลใน `src/data/flowers.js` ให้มี `id` ไม่ซ้ำและไม่เปลี่ยนภายหลัง, `name`, `english`, `family`, `color`, `center`, `form`, `meaning` และ `description` หน้ารายการสร้างจากข้อมูลและแบ่งหน้าอัตโนมัติ ตัวตรวจสอบข้อมูลทดสอบกับ 100 รายการไว้แล้ว

ใช้ `form` ที่มีอยู่ 12 แบบ หรือเพิ่มรูปทรงใน `scene/flowers.js` และรายการรูปทรงที่ยอมรับใน `validateCatalog` โมเดลเป็นการตีความแบบ clay toy ไม่ใช่ภาพระบุชนิดทางพฤกษศาสตร์ ชั้นวางในฉากแสดงดอกไม้ตัวอย่าง 8 ชนิด ส่วนหน้ารายการเข้าถึงครบ 50 ชนิด โดยไม่ต้องวางทุกโมเดลในโลก 3D พร้อมกัน ภาพย่อสร้างทีละรูปเฉพาะหน้าปัจจุบันและเก็บใน cache หากอุปกรณ์สร้าง WebGL context สำหรับภาพย่อไม่ได้จะใช้ภาพ SVG ที่สร้างในโปรเจกต์แทน

## พื้นฐานเวอร์ชันถัดไป

`features/keepsakes/model.js` เตรียมข้อมูล JSON ที่มีเวอร์ชันแยกไว้แล้ว:

- **จัดช่อดอกไม้:** `createBouquetDraft()` เก็บก้านแต่ละดอกด้วย `flowerId`, ตำแหน่ง, การหมุน และขนาด พร้อมสีกระดาษ/ริบบิ้น ต่อกับ factory ดอกไม้เดิมได้
- **การ์ดข้อความ:** `createCardDraft()` มีผู้รับ ข้อความ ผู้ส่ง และพาเลต เมื่อทำ editor ให้ใช้ข้อความผ่าน `textContent` หรือวาดบน canvas และกำหนดขนาดข้อความ
- **PNG:** แยกโมดูล export ภายหลัง ใช้ render target หรือเรนเดอร์เฟรมเฉพาะแล้ว `canvas.toBlob()` ไม่เปิด `preserveDrawingBuffer` ค้างไว้เพื่อหลีกเลี่ยงต้นทุนบนมือถือ
- **วิดีโอ:** ใช้ `canvas.captureStream()` กับ `MediaRecorder` และตรวจ `isTypeSupported()` ก่อนใช้ ให้มีทางเลือก PNG บนเบราว์เซอร์ที่ไม่รองรับ

ฟีเจอร์เหล่านี้ **ยังไม่เปิดใช้งานใน V1** ไม่ต้องใช้บริการภายนอก สามารถเพิ่มการบันทึกในเครื่องผ่าน IndexedDB ภายหลังได้

## การเข้าถึงและข้อจำกัด

- ข้อมูลดอกไม้มีปุ่ม HTML เป็นทางเลือกให้ผู้ใช้คีย์บอร์ดโดยไม่ต้องคลิกวัตถุ 3D; กด Escape เพื่อปิดหน้าต่างได้
- ระบบลดการเคลื่อนไหวจะข้ามการเดินกล้องและหยุดแอนิเมชันต่อเนื่อง แต่ไม่ข้ามคำทักทาย Render loop หยุดเมื่ออยู่นอกฉากแนะนำตัว/การเคลื่อนกล้อง และเมื่อแท็บอยู่เบื้องหลัง
- จำกัด pixel ratio และ shadow map เพื่อช่วยมือถือ โมเดลสร้างในเครื่องและไม่มี asset ภายนอก แต่ GPU รุ่นเก่าอาจทำงานช้า
- E2E ขนาดมือถือเป็นการจำลองใน Chromium ไม่ใช่การรับรองอุปกรณ์จริงทุกเครื่อง ควรตรวจ Safari/iOS และ Android จริงก่อนเผยแพร่วงกว้าง
- ความหมายดอกไม้เป็นข้อความเชิงสร้างสรรค์สำหรับเกม ไม่ใช่ข้อมูลพฤกษศาสตร์หรือคำแนะนำทางการแพทย์
